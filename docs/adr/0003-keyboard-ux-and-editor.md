# ADR 0003: 키보드 UX(Mac/PC 표기)와 에디터 설계

- 상태: **채택** (2026-11-05)
- 관련: [keyboard.md](../keyboard.md), [ADR 0002](0002-keymap.md), SPEC 7.3, 7.4, 7.7

## 1. 키보드 UX (사용자 결정: A~D 채택)

Mac 배열 사용자는 Cmd 조합을 쓸 수 없어서 Ctrl, Option, fn이 섞이면 헷갈립니다. 그래서 다음 네 가지를 모든 앱(데스크톱, 파일 관리자, 에디터)에 공통으로 적용합니다.

**A. 키보드 표기 설정**
- `~/.config/tuidesk/config.toml`의 `keyboard = "mac" | "pc"` 값에 따라 메뉴, 도움말, 힌트 줄의 단축키 표기를 바꿉니다.
  - Mac: `⌃S`, `⌥↓`, `fn F2`, `fn↓`(PgDn)
  - PC: `Ctrl+S`, `Ctrl+End`, `F2`, `PgDn`
- 처음 실행할 때 한 번 물어보고, 런처 › Settings에서 바꿀 수 있습니다.
- 리눅스 콘솔은 기호 글꼴이 없어서 항상 PC 표기를 씁니다.

**B. Mac 규칙은 두 개만**
- **명령은 ⌘ 대신 ⌃(Ctrl)**를 씁니다. 저장 ⌃S, 실행취소 ⌃Z, 찾기 ⌃F, 전체 선택 ⌃A가 이 규칙을 따릅니다.
- **⌥(Option)+방향키는 크게 이동**합니다. ⌥←/→는 단어 단위, ⌥↑/↓는 문서 처음과 끝으로 이동합니다.
- Option 조합 명령(⌥., ⌥Enter)은 숨은 보조 키로만 남기고, 메뉴와 ⌃ 키를 주 사용법으로 안내합니다.

**C. 메뉴 바 + 명령 검색**
- 에디터와 파일 관리자 위쪽에 File / Edit / View 같은 메뉴를 두고, 메뉴마다 단축키를 함께 표시합니다. 메뉴 바는 F10이나 클릭으로 엽니다.
- **⌃K 명령 검색**: 명령 이름의 일부만 입력해도 찾아서 실행합니다. 모든 명령은 명령 레지스트리 하나에서 이름, 단축키, 실행 함수를 함께 관리합니다. 그래서 메뉴, 검색, 힌트가 항상 같은 정보를 보여 줍니다.

**D. 하단 힌트 줄**
- 상황에 맞는 주요 단축키를 키보드 표기 그대로 한 줄로 보여 줍니다(nano 방식). 설정에서 끌 수 있습니다.

Alt+글자로 메뉴를 여는 방식(Windows의 Alt+F)은 쓰지 않습니다. 콘솔에서 Alt+B/F가 단어 이동 키와 겹치기 때문입니다.

## 2. 에디터 기본 키 (별칭 포함)

| 동작 | 키 (PC 표기) | Mac에서 | 콘솔 |
|---|---|---|---|
| 저장 / 탭 닫기 | Ctrl+S / Ctrl+Q | ⌃S / ⌃Q | 같음 |
| 실행취소 / 다시실행 | Ctrl+Z / Ctrl+Y | ⌃Z / ⌃Y | 같음 |
| 복사 / 잘라내기 / 붙여넣기 | Ctrl+C / X / V | ⌃C / ⌃X / ⌃V 또는 ⌘V | 같음 |
| 전체 선택 | Ctrl+A | ⌃A | 같음 |
| 찾기 / 바꾸기 / 줄 이동 | Ctrl+F / Ctrl+R / Ctrl+G | ⌃F / ⌃R / ⌃G | 같음 |
| 다음 / 이전 찾기 | F3 / Shift+F3 (찾기 창에서는 ↓ / ↑) | fn F3 | 같음 |
| 줄 처음 / 끝 | Home / End | fn← / fn→ | Home / End |
| 단어 이동 | Ctrl+← / →, Alt+← / → | ⌥← / ⌥→ | Alt+B / Alt+F |
| 문서 처음 / 끝 | Ctrl+Home / End, Alt+↑ / ↓ | ⌥↑ / ⌥↓ | Ctrl+Home / End |
| 한 화면 위 / 아래 | PgUp / PgDn | fn↑ / fn↓ | PgUp / PgDn |
| 선택 | 이동 키 + Shift | 이동 키 + ⇧ | **⌃Space로 선택 시작 표시** 후 이동(Shift가 사라지기 때문) |
| 들여쓰기 / 내어쓰기 | Tab / Shift+Tab | 같음 | Tab / (메뉴) |
| 스니펫 삽입 | 트리거 단어 + Tab, Ctrl+T | ⌃T | 같음 |
| 명령 검색 | Ctrl+K | ⌃K | 같음 |
| 메뉴 바 | F10 | fn F10 | F10 |

- SPEC 7.4는 스니펫 팔레트 키를 Ctrl+Space로 정했습니다. 그런데 맥에서 Ctrl+Space는 한/영 전환 키라서, 스니펫 팔레트는 Ctrl+T로 정합니다. Ctrl+Space는 콘솔용 선택 시작 표시로 씁니다.
- Mac의 fn← / fn→ / fn↑ / fn↓가 Terminal.app에서 앱까지 전달되는지는 아직 실측하지 않았습니다(keyboard.md 4장). 전달되지 않으면 Terminal.app 설정 프로필(제안 E)로 해결합니다.

## 3. 에디터 구현 방식

- **micro 코드를 이식하지 않고 직접 작성합니다.**
  - micro의 문법 정의는 YAML이라 YAML 의존성이 추가되고, 버퍼, 렌더러, 키 처리 구조가 우리 캔버스, 키 정규화, 명령 레지스트리와 맞지 않습니다.
  - 필요한 범위(줄 단위 버퍼, 실행취소, 선택, 찾기/바꾸기, 정규식 규칙 기반 색칠)는 직접 만드는 편이 더 작고 테스트하기 쉽습니다. 이 결정으로 micro 라이선스 고지도 필요 없습니다.
- **버퍼**: 줄 배열(`[][]rune`)로 관리합니다. 실행취소 단위는 연속 입력을 하나로 묶습니다(입력 종류가 바뀌거나, 커서를 옮기거나, 시간이 지나면 끊음).
- **문법 색칠**: 언어마다 정규식 규칙을 둡니다(주석, 문자열, 키워드, 숫자, 지시어). 화면에 보이는 줄만 칠합니다. 여러 줄에 걸친 문자열이나 주석은 우선 지원 언어에 필요한 범위에서만 처리합니다.
- **설정·스니펫 파일 형식**: TOML입니다. 이를 위해 `github.com/BurntSushi/toml`(MIT, 다른 의존성 없음)을 추가합니다.
- **sudo 저장**
  - `sudo -S -k -p '' tee -- <경로>`를 실행하고, 표준 입력으로 비밀번호 한 줄과 파일 내용을 넘깁니다.
  - 비밀번호는 입력 위젯의 비밀번호 모드로 받아서, 넘긴 직후 지웁니다. 로그와 실행취소 기록에는 남기지 않습니다.
- **저장 후 검사기**: 경로 패턴에 맞는 명령을 실행합니다(기본값: `/etc/nginx/**` → `nginx -t`). 결과는 토스트로 알리고, 실패하면 출력을 보여 주는 창을 엽니다. 검사 명령에 root 권한이 필요하면, 방금 입력한 sudo 비밀번호를 같은 저장 과정 안에서만 한 번 더 사용합니다.
