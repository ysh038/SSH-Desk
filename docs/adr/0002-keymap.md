# ADR 0002: 기본 키맵 — macOS Terminal.app과 리눅스 콘솔에서 모두 동작하는 키

- 상태: **채택** (2026-11-04)
- 관련: SPEC 7.1, 7.3, 9.0, [compat-matrix](../compat-matrix.md) 발견 2·4·5

## 배경

지원 대상은 두 곳입니다. 둘 다에서 키가 앱까지 전달되어야 합니다.

**① macOS Terminal.app → ssh**: macOS가 먼저 가로채는 키가 있습니다(기본 설정 기준).
- `Ctrl+Space`: 입력 소스 전환(한/영)
- `Ctrl+←/→/↑/↓`: Mission Control, 데스크톱 공간 전환
- `F11`: 데스크톱 보기
- `Cmd+…`: 원격으로 전달되지 않음
- 또한 맥 키보드의 F키는 기본적으로 밝기, 볼륨 키라서 `fn`과 함께 눌러야 합니다.

**② 리눅스 콘솔**(QEMU VT에서 측정)
- `Alt+←/→`, `Alt+F1~F12`: 가상 콘솔 전환
- `Shift/Ctrl+방향키`, `Shift+Tab`: 수정키가 사라짐
- `Ctrl+H`: Backspace와 구분되지 않음
- `Shift+F10`: `F20`으로 들어옴

## 결정

### 입력 정규화 (`internal/term/keys.go`)
- 모든 키는 `term.Key`로 정규화한 뒤 `"Ctrl+W"`, `"Shift+F6"` 같은 정식 이름으로 매칭합니다.
- `Ctrl/Alt + 두벌식 자모`는 영문 키로 바꿉니다(`Ctrl+ㅈ` → `Ctrl+W`).
- `F13` 이상의 F키는 `Shift+Fn`으로 바꿉니다. 리눅스 콘솔은 10을 빼고(F20 → Shift+F10), xterm 계열은 12를 뺍니다.
- **이벤트는 앱이 먼저 받습니다.** 포커스된 창의 앱이 처리하지 않은 키만 데스크톱으로 넘어옵니다. 그래서 Tab, Ctrl+Q는 에디터 같은 앱이 먼저 쓸 수 있습니다.

### 데스크톱 전역 키

| 동작 | 기본 키 | 보조 키 | 비고 |
|---|---|---|---|
| 런처(시작 메뉴) | **F9** | Ctrl+Space(콘솔), 상단 바 "≡ 메뉴" 클릭, 바탕화면 우클릭 | SPEC의 Ctrl+Space는 macOS 입력 소스 전환과 겹쳐서 보조 키로 내림 |
| 다음 창 | **F6** | Tab(앱이 쓰지 않을 때) | |
| 이전 창 | **Shift+F6** | Shift+Tab(Terminal.app) | 콘솔은 Shift+F6이 F16으로 들어오며 정규화로 처리 |
| 창 메뉴(컨텍스트 메뉴) | **Shift+F10** | 우클릭, Ctrl+클릭 | 콘솔은 F20으로 들어오며 정규화로 처리. 창 메뉴에서 최대화, 최소화, 이동, 크기, 닫기 |
| 창 이동 모드 | **F7** | 제목줄 드래그 | 방향키로 이동, Enter나 Esc로 끝냄 |
| 창 크기 모드 | **F8** | 오른쪽 아래 모서리 드래그 | 방향키로 조절, Enter나 Esc로 끝냄 |
| 창 닫기 | **Ctrl+W** | 제목줄 [x] | |
| 새 창 | **Ctrl+N** | 런처 › 새 창 | |
| 최대화 토글 | 창 메뉴 | 제목줄 [^], 제목줄 더블클릭 | |
| 최소화 | 창 메뉴 | 제목줄 [_] | 작업표시줄이나 런처의 창 목록에서 복원 |
| 메뉴, 다이얼로그 닫기 | **Esc** | 바깥 클릭 | |
| 데스크톱 종료 | **Ctrl+Q** (확인 창) | 런처 › 종료 | 앱이 Ctrl+Q를 쓰면 앱이 먼저 받음 |
| 도움말 | **F1** | 런처 › 도움말 | |

메뉴와 리스트 안에서는 `↑/↓`, `Home/End`, `PgUp/PgDn`, `Enter`, `Esc`를 씁니다. 메뉴 항목의 밑줄 글자(단축 글자)를 눌러도 됩니다.

| 동작 | 키 | 비고 |
|---|---|---|
| 열기 / 폴더 진입 | Enter | 더블클릭 |
| 상위 폴더 | Backspace | |
| 선택 토글 | Space | |
| 이름 바꾸기 | F2 | |
| 새로고침 | F5 | |
| 숨김 파일 토글 | Alt+. | Ctrl+H는 콘솔에서 Backspace와 같음 |
| 경로 입력 | Ctrl+L | 경로 바 클릭 |
| 필터 | 글자 입력 | Esc로 해제 |
| 잘라내기 / 복사 / 붙여넣기 | Ctrl+X / Ctrl+C / Ctrl+V | |
| 복제 | Ctrl+D | |
| 휴지통으로 | Delete | |
| 실행취소 | Ctrl+Z | |
| 컨텍스트 메뉴 | Shift+F10, 우클릭, Ctrl+클릭 | 앱 메뉴가 먼저, 바깥 테두리는 창 메뉴 |
| 권한 | 메뉴 › Permissions… | Alt+Enter 후보(콘솔 확인 후 확정) |

앱은 F6~F9, Shift+F6, Ctrl+W, Ctrl+Q처럼 데스크톱 전역 키는 쓰지 않는다.

### 쓰지 않는 키
- `Alt+방향키`, `Alt+F1~F12`: 콘솔 전환
- `Ctrl+방향키`: macOS Mission Control
- `F11`: macOS 데스크톱 보기
- `Ctrl+H`: Backspace와 같음. SPEC 7.2의 "숨김 파일 토글"은 Phase 2에서 다른 키로 정합니다.
- `Shift+방향키` 선택: 콘솔에서 동작하지 않습니다. 에디터에는 별도의 "선택 시작" 키가 필요합니다(Phase 3).

## 결과
- 사용자 설정(`config.toml`)으로 키를 바꾸는 기능은 SPEC 7.7에서 다룹니다. 이 표가 기본값입니다.
- 새 단축키를 추가할 때는 이 문서의 "쓰지 않는 키"와 겹치지 않는지 확인하고, 리눅스 콘솔 VM에서 확인합니다.
